# BE-Aero Desktop v1.2.6

A small fix for the AI chat.

## Fixed

- **You can select and copy the assistant's answers.** Drag across any message to select it, then
  press Ctrl+C or right-click > Copy. Before, the chat's text couldn't be selected at all.
- **Selecting text no longer moves the chat widget.** In the free-form layout, pressing inside the
  chat used to start dragging the whole widget. Move it by its title bar instead.

Everything from [v1.2.5](https://github.com/BE-AI-Research/be-aero-desktop/releases/tag/v1.2.5)
(connected devices, file browser, File Pool, state sync, AI bus and more) is included.

## Install and update

Installed Windows copies update automatically.

Linux install or update:

```bash
curl -fsSL https://github.com/BE-AI-Research/be-aero-desktop/releases/latest/download/install-linux.sh | sudo bash
```
